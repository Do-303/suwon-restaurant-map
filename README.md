# 🏯 수원 맛집 지도

정조의 도시, 수원(水原華城) 근처 식당을 지도에서 찾아보는 웹 앱이에요.
Google Maps JavaScript API의 Geolocation 예제를 바탕으로 만들었어요.

## 주요 기능
- **음식 종류 칩**: 전체 · 한식 · 중식 · 일식 · 양식 · 아시안 · 기타 해외 · 술집 · 카페 · 베이커리
- **별점 등급 핀**
  - 🔴 빨강: 별점 4.5 이상
  - 🟢 초록: 별점 4.0 ~ 4.4
  - 🔵 파랑: 별점은 4.0 미만이지만 리뷰가 많은 곳 (100개 이상)
- **🏯 수원 명물**: 왕갈비 · 통닭거리 통닭 · 지동 순대곱창 · 군만두·쫄면 (검색어로 찾기)
- **근처 명소**: 수원화성·성곽길, 화성행궁, 행리단길, 광교호수공원, 스타필드 수원, 효원공원·월화원, 일월수목원, 영흥수목원 — 누르면 이동해서 주변 식당을 보여줌
- **보기 필터**: 색깔별 모아보기, 🕐 영업 중, 🏠 토박이 추천, 프랜차이즈 제외
- **🏠 수원 토박이 추천**: 코드의 `LOCAL_PICKS`에 가게 이름을 적거나, 앱에서 직접 표시
- **📍 내 위치**, **🔍 이 지역 식당 찾기**
- 흰색·회색·검정 톤 + 코드로 그린 한지 질감 + 수원화성 성곽(여장)·문살 무늬
- 정조대왕 엄지척 캐릭터 아이콘 (직접 그린 오리지널 SVG)

## 실행 방법
1. `index.html`을 브라우저로 열어요.
2. Google Maps API 키를 입력해요.
   - Google Cloud 콘솔에서 **Maps JavaScript API**와 **Places API (New)**를 켜야 해요.
   - 키를 `index.html`의 `const API_KEY = "";`에 직접 넣어도 돼요.
     이때는 꼭 **웹사이트(HTTP referrer) 제한**을 걸어 주세요.

> 🔑 이 레포에는 API 키가 들어 있지 않아요.
